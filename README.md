# Audrey's portfolio

A responsive, dependency-free personal portfolio. Open `index.html` in a browser to preview it; no build step is needed.

## Customize

- Edit project descriptions and experience in `content.js`.
- Add your email, LinkedIn, GitHub, and résumé URL in `content.js` under `contact`. Blank links stay hidden.
- Replace “Audrey” and “Harvard ’28” in `index.html` if desired.
- Add a portrait at `assets/profile.jpg`. It replaces the portrait placeholder automatically.
- Add project photos to `assets/`, then set each project's `image` field in `content.js`, for example `image: "assets/hht-chart.jpg"`.
- Review the project copy before publishing, particularly work involving unpublished or company research.

## Publish with GitHub Pages

Create a GitHub repository, upload the contents of this folder to the repository root, then in **Settings → Pages**, select **Deploy from a branch**, `main`, and `/ (root)`. GitHub will provide the published URL. You can also edit the files directly in GitHub later.

No personal contact information, résumé, or photos are included yet.
